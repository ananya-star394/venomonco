# Worksheet export and literature-linked candidate catalogue (v2.2)

- Research Workbench worksheet rows now render in an on-page table before export.
- Rows persist in browser local storage on the same device/browser; they are not sent to a server or shared across users.
- CSV download is a separate action and exports all visible worksheet rows.
- Explorer includes a 20-entry literature-linked candidate discovery table. Some entries have direct papers; others are explicitly marked as discovery leads or require assay-level primary-source curation.
- Chlorotoxin links to experimental PDB 7X41, with the known “construct differs” warning. Other candidates use RCSB search links rather than invented PDB IDs.
- The catalogue must not be described as 20 fully curated database assay records: it is a research-discovery index and is kept separate from the relational evidence tables until full source-level curation is complete.
