# Snake healthcare / drug-discovery context: source notes

The Explorer's healthcare column is intentionally conservative. It reports established venom-inspired drug-discovery lineages only for selected species, and labels all other species as not yet curated rather than inventing an indication. A source link is supplied per row.

- **Bothrops jararaca** — bradykinin-potentiating peptides from this species inspired ACE-inhibitor drug design, including captopril. The drug is synthetic; this is not an anticancer treatment. Review: https://pubmed.ncbi.nlm.nih.gov/21447352/
- **Echis carinatus** — echistatin inspired the antiplatelet drug tirofiban. This is cardiovascular/antiplatelet drug discovery, not anticancer treatment. Review: https://pubmed.ncbi.nlm.nih.gov/31137917/
- **Sistrurus miliarius barbouri** — barbourin inspired eptifibatide, an antiplatelet drug. This is not anticancer treatment. Review: https://pubmed.ncbi.nlm.nih.gov/31137917/
- **Bothrops atrox / Bothrops moojeni** — batroxobin is discussed in literature as a venom-derived fibrinogen-active enzyme with region-dependent use/regulatory context. Do not assume approval in every jurisdiction. Review: https://pmc.ncbi.nlm.nih.gov/articles/PMC10605524/
- **Naja atra / Naja naja atra** — cobrotoxin/cobratide has been discussed in analgesic contexts in literature; clinical/regulatory claims need current jurisdiction-specific verification. Review: https://www.frontiersin.org/journals/bioengineering-and-biotechnology/articles/10.3389/fbioe.2021.811905/full

The literature links are evidence-discovery starting points, not proof that a treatment is approved locally or that research is currently ongoing. “Ongoing” must be supported by a dated paper, registry entry or official project source. A species reference does not establish anticancer activity.
