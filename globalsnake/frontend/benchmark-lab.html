Benchmark Lab

Evaluate how closely a system's evidence labels match a human-adjudicated reference set. Every row must be tied to a real source; this page deliberately starts empty.

Important: no benchmark observations are prefilled or fabricated. Enter records only after checking primary literature and applying the written protocol. v2.6 stores records in MySQL through the PHP API, shared by users who access the same installation. Apply database/migrate_v26_benchmark.sql first. This prototype does not implement login or role-based authorization; use only in a trusted local environment until access controls are added. “Not established” means the reviewed source set did not establish the claim under the defined protocol—not proof of biological inactivity.
